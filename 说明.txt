DaVinci Beauty 美颜插件 —— 交付说明

【当前构建 2026-11-07】1.0.8.0：GPU 磨皮把读回耗时拆成「等 GPU」与「读 staging」两项、ROI 外补齐前移到 Map 之前（画面逐字节不变，5/5 台架）；同批修正台架口径，推翻「GPU 比 CPU 慢」的旧结论（GPU 实际快 2.4~4.7 倍）。1.0.7.0 掩码改双 R8 + 读回只拷输出矩形；1.0.6.0 CPU 磨皮按 ROI 裁剪，1.0.5.0 修多实例串台。版本号自 2026-11-06 起为四段式，下面「v3.0.x」段落是旧口径历史。

【当前状态 2026-11-03】v3.0.0 已把引擎从旧版闭源商业 SDK 整体替换为自研纯 CPU 美颜引擎（CoreEngine）+ ONNX 人脸检测，并在引擎内自动检测 GPU / 退回 CPU，可作为最终版日常使用。当前最新 v3.0.9：**修的是方向，不是强度** —— ① 掩码的「脖子通道」改锚到下巴一侧（Resolve 的帧是 bottom-up，旧写法把 0.65 脸高的脖子整块铺到了发际线以上，这就是「遮罩比额头还高一大截」；修后改动区上沿从 y=21 收到 y=136，脸框上沿本身是 146）；② 五官立体 / 去黑眼圈 / 去法令纹的椭圆偏移与旋转角按帧行序取反（此前沿 y 镜像：黑眼圈落在上眼睑、法令纹落在眉弓、立体压暗落到头顶之上）；③ 肤色自适应中心的采样带在 bottom-up 下改到脸颊（此前采到额头与头发，中心被拉偏、掩码变薄，效果跟着变弱）；④ 修好本整合包里跑不起来的构建：`build.ps1` 只认 `07_*` 目录，而目录已改名 `02_引擎资产`。top-down 路径逐字节不变（18/18 基线 md5 一致）。当前最新 v3.0.8：**工程收口，画面逐字节不变** —— ① 构建链路改为 PowerShell 驱动（旧 build.bat 把 ONNX 头文件路径以 GBK 写死，控制台代码页一变就报「打不开 onnxruntime_c_api.h」，本次验收第一步即复现）；② 装机判据从 `net session` 改为「能否创建目标目录」，修受限管理员令牌下的误报；③ 8bit 且行无填充时引擎直接读写宿主图像，省掉两次全帧拷贝（1080p 24.5→20.5 ms）；④ mock host 新增 14 个滑块逐个独奏用例（共 23 项），补上立体/亮眼/去眼袋/去法令纹/祛斑/红润从未单独测过的空白；⑤ 清掉 v2.x 遗留的 20 个死成员与 7 个死方法声明，修 `faceScore_` 截断告警与 `version()` 静态串悬空风险。v3.0.7：**加强磨皮强度并放大四组档位差异** —— ① 磨皮本身引入「强度总增益」（dst = src + (dst−src)×1.8），满档在人脸区的平均改动从 1.01 灰阶提到 1.82、峰值从 13 提到 23，解决「磨皮 0 → 100 看不出变化」；② 「磨皮算法」：高斯档半径 ×2（此前 5×5 盒平均几乎没糊开）、弱磨皮强度 0.5→0.30；③ 「磨皮模式」：清晰 fine×4.0+mid0.45、精细 fine×5.5+mid0.75、轻磨皮 0.55→0.40。四组档位之间与源帧的差异全部约翻倍（高斯 1.007→1.467、弱磨皮 0.492→1.159、清晰 0.241→0.477、精细 0.400→0.720、轻磨皮 0.442→0.972）。v3.0.6：修掉「磨皮算法」「磨皮模式」两个下拉框的**面板侧**缺陷 —— ① 参数读取还留着 SDK 时代的重映射 map[3]={1,0,2}，把「双边滤波」和「高斯」对调；② 高斯档下细节回填强度恒为 0，磨皮模式四档完全失效。v3.0.5 修掉两个「只有大眼正常」的真机 bug —— ① 瘦脸/下巴的 y 方向语义在 bottom-up 缓冲里是反的（下巴底取到发际线、嘴线取到额头、瘦脸高斯中心跑到眉毛），现已按行序取反；② 「磨皮算法」三档与「磨皮模式」四档此前从未被读取（三档输出逐位相同），现已真正接线。v3.0.4 修正帧行序（OFX/Resolve 的帧是 bottom-up，第 0 行是画面最下面一行，检测此前按 top-down 读，脸是上下颠倒的，真机实测 score 0.25/0 脸 → 0.93/1 脸）；v3.0.3 修掉三个「假故障」——离线自测夹具把文件路径当成图像（导致此前所有离线「0 检出」结论作废）、异步检测在按需渲染宿主（Resolve 单帧/静止画面）里永久透传、参数句柄取不到时静默给 0 导致引擎逐字节透传。v3.0.2 修正了人脸检测预处理（喂原始 0-255，去掉归一化）。

【安装前】
  必须先完全退出 DaVinci Resolve；安装后重启它才能识别新插件。
  不退出就装的话，被占用的 DLL 会被改名成 .locked-<pid> 留在目录里
  （这就是此前堆积 139 MB 垃圾的原因）。

【使用】
  效果库 -> OpenFX -> DaVinci Beauty -> 把「DaVinci Beauty 美颜」拖到片段上。
  默认已给 磨皮 50 / 美白 30 / 红润 30，拖上去就有轻度美颜。
  提示：磨皮不为 0 时锐化不生效（要锐利感请用「清晰」）；八项全 0 时画面完全不变。
