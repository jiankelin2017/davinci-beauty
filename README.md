> **当前构建：1.1.1.3（2026-11-07）** —— **真机取样把上一版的前提推翻了**。37 条诊断（1080p、420 帧）显示：`盒` 中位 **32.5%**、`脸盒` 22.9%、**`倍数` 中位 1.4x（1.2~1.6）**、`皮肤` 7.78%、`脖/皮肤` 35%，脸数 3 脸 19 条 / 2 脸 16 条 / 1 脸 2 条。上一轮「倍数 15~25 倍」的猜测**错了一个数量级**——错在把「ROI 占全帧比例」当成了「相对脸框的倍数」。40% 的额外面积来自脖子：`len=0.65h` 把掩码盒高撑到 `1.65h`，除以脸盒 `1.15h` 得 **1.43x**，与实测 1.4 吻合；肤色判据没有误判（皮肤远小于脸盒）。但 ROI 里**只有 24% 的像素是皮肤**（`盒÷皮肤 = 4.2`），浪费主体是「一个矩形盖住多张脸之间的空隙」，只能靠拆多矩形解决。所以本版新增第四个统计 `tileA`（每张脸单独成块时的块面积之和，含各自 pad 与脖子带），日志加 **`分块 = tileA ÷ 盒`**：≥1 说明单矩形并不吃亏、拆了白拆，**<0.9 才是多矩形重构的真信号**。统计只读，逐字节基线 18/18、mock_host 23/23 与上一版完全相同。附带硬结论：**2c 延迟取回在这段素材上命中率 0**（稳态 7 条采样 `取=0` 全中，`阻=rect` 6 / `noprev` 1）。按四段式判定，日志字段增加属**构建位**。

> 更早一版：**1.0.10.2（2026-11-07）** —— 诊断期临时加密采样：GPU 磨皮那行日志的周期从每 60 帧改成每 10 帧（构建位 +1），只改一个取模常量与 ini 注释里对应的一句。**加密后的 40 个样本推翻了上一版的两条结论**：①`Map` 不是恒 0.02 ms（19 % 的帧 2~14.56 ms）；②首帧慢不必用「冷启动伪影」解释，与稳态是同一种阻塞。最有价值的发现是**责任划分**——36 个有效样本按整帧间隔分成「按时帧 25 / 掉帧 11」，CPU 侧三项（拷 0.90→0.99、补齐 0.72→0.70、算 0.15→0.18）几乎不动，多出的 6~14 ms 全落在两个 GPU 同步点（写侧 `Map` 0.02→3.60、读侧等 GPU 1.23→3.48）。23.976 fps 下约 **18 % 的帧超预算**。据此 2c 从「放弃」改回「待实施」（已在 1.1.0.0 落地）；「区间均值递增＝热节流」的猜测也作废（380 帧在 5.0~5.5 之间横摆，后半段反而回落）。1.0.10.1 是纯观测版：把 `uploadMs` 拆成「Map 阻塞」与「纯 memcpy」（`upMapMs` / `upMemMs`），不改任何逻辑与画面。1.0.10.0 修 1.0.9.0 的一个实装缺陷：那次承诺的「初始化日志打出适配器型号」在生产路径上从未生效，因为播报写在 `gpuSmoothInit()` 里而插件本体不调用它（走 `gpuSmoothRgbBand` 内的懒加载），1.0.9.0 的产物里连该字符串都不存在。本版把播报移到懒加载处并用 `g_initLogged` 保证只打一次。算法与画面未动，18/18 逐字节一致。1.0.9.0 `gpu_smooth` 出厂默认从 `off` 改为 `auto`（真机目视确认通过：1080×1920、磨皮 94、4928 帧零回落，无色块/断层、边缘无糊、亮度无偏）；1.0.8.0 GPU 磨皮把 `mapMs` 拆成「等 GPU」与「读 staging」，并把 ROI 外补齐前移到 Map 之前（实测重叠率 8~18%，未达预期），同批修正台架口径错误，据此推翻 1.0.7.0 的「GPU 比 CPU 慢」结论。1.0.7.0 GPU 磨皮搬运瘦身（掩码改双 R8、读回只拷输出矩形）；1.0.6.0 CPU 磨皮按 ROI 裁剪；1.0.5.0 修掉 BUG4 多实例串台；同批补齐 GPL-2.0-only 许可证与第三方声明。2026-11-06 起版本号改用四段式，下文「v3.0.x」是旧口径的历史记录，两者的对照表见 `01_ofx插件源码/PROGRESS.md`「版本号规则 v2」第 (4) 节。

## 恢复方法

1. 把 `01_ofx插件源码` 放回任意目录，并在 `02_引擎资产\` 放好引擎资源
   （`onnxruntime.dll` + `yunet.onnx`，从交付包或已装机的 bundle 取回），
   或直接用 `bundle\...\Contents\Win64`、已安装的 bundle；
2. 运行 `build.bat` 编译，再运行 `install.bat` 安装；
3. 启动 DaVinci Resolve，效果库 → OpenFX → DaVinci Beauty → 「DaVinci Beauty 美颜」。

> 注意：改了插件之后**必须重启 Resolve**。
> OFX 缓存 `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\OFXPluginCacheV2.xml`
> 按「mtime + size」判断插件是否失效。
